## Cómo ejecutar
1. Instalar dependencias: `pip install -r requirements.txt`
2. Ejecutar: `python main.py`
3. Abrir el enlace que aparece en la consola (normalmente http://127.0.0.1:7860)

## Notas
- Usar la pestaña "Cargar clínicas de ejemplo" para agilizar las pruebas.
- La pestaña "Casos de prueba" ejecuta automáticamente los 5 casos del enunciado.
